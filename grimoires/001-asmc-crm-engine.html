Phase 00 · System Core
The Closed-Loop Revenue System
This is a full-stack CRM built for a construction business, documented here as a proof-of-work artifact. Published under ASMC — the client stays anonymous. What it is: not a CRM setup, not a funnel. A closed-loop, self-monitoring, self-correcting revenue system. Every tool, field, Zap, and sequence plugs into one loop: INPUT → NORMALIZE → RESPOND → TRACK → DECIDE → ROUTE → CONVERT → ANALYZE → CORRECT → LOOP. Nothing sits idle. Nothing falls through.
Self-healing Intent-scored SLA-enforced 24 Zaps 76 Fields verified Zero dead leads
System philosophy: Automation first, human override always. Every contact is either in an active sequence, has an open task, or is on a scheduled re-engagement date. The system self-heals stagnation before a human notices it.

The 11-step closed loop
1
INPUT All entry points
Ads (Meta/Google) · Form submits · Inbound calls · Manual entry · SMS reply. On entry: Contact created/updated → lifecycle_stage = TOFU → engagement_status = NEW → intent_score = 0 → Opportunity created → Owner assigned. Reporting starts here.
2
NORMALIZE Anti-chaos engine
Immediately after entry: check for lifecycle_stage, owner, opportunity, source. If missing → auto-fix. Duplicate check: if phone/email exists → merge, keep highest intent_score. Prevents data fragmentation — the silent killer of CRM systems.
3
RESPOND Speed + first impression
SMS fires instantly. Email fires at 2 min. first_response_timer starts at contact creation. When lead replies: first_response_time = NOW − created → engagement_status = ENGAGED → intent_score += 3. Response is not just action — it is measured behavior.
4
TRACK INTENT Core brain
Every behavioral event updates intent_score and last_activity_timestamp: SMS reply (+3) · Email click (+2) · Page visit (+1) · Call activity (+3) · Booking created (+5) · Estimate viewed (+4). Score feeds routing in real time.
5
CALLS High-weight signals
Inbound call → intent_score += 3. Missed call → auto-SMS + callback task. Connected call → outcome tagging within 2min. Outbound no-answer → retry sequence. All calls tracked: response time, contact rate, call-to-book rate.
6
PIPELINE MOVEMENT Data generator
Every stage move: lifecycle_stage update → entered_stage_timestamp set → time_in_stage reset. Logs: conversion progression, drop-off points, stage velocity. Pipeline is not visual — it is a data engine.
7
DECIDE + ROUTE Operations brain
System evaluates: intent_score + source quality + stage + time delays → assigns owner / escalates / triggers AI call / moves stage / recycles. SLA enforcement runs in parallel — escalation ladder fires automatically.
8
CONVERT BOFU
Lead books → BOFU → confirmation + reminders. After appointment: Won → revenue logged + Phase 3 trigger → Lost → recycle → No-show → rebooking loop. Close rate, show rate, revenue attribution all logged automatically.
9
STAGNATION DETECTION Self-healing
TOFU > 24hr → problem flag. MOFU > 3 days → nurture issue. BOFU > 2 days → sales issue. System actions: create task → escalate → reassign. No lead sits idle without a trip wire on it.
10
RECYCLE + RE-ENTRY Long-term money
When lead cools: move to RECYCLE → enter 12-month passive nurture. When any activity returns: move to MOFU → intent_score += boost → instant response triggered. Tracking: reactivation rate, time-to-re-engage, revenue from recycled leads.
11
REPORTING EMBEDDED Not a layer on top
Every action feeds metrics in real time: INPUT (volume, source quality) → RESPONSE (speed) → ENGAGEMENT (intent flow) → PIPELINE (movement) → CONVERSION (revenue) → RECYCLE (recovery rate). You see where leads slow, where they drop, where they convert.

Foundation workflows — build these first
Build these three GHL workflows before any Zap. They are the operating system that all 24 Zaps plug into. Zaps without these workflows create noise — contacts with no stage, no score, no owner.

Contact created/updated → normalize + lifecycle assign
▶
T
Trigger: Contact Created OR Contact Updated
1
Check: if lifecycle_stage is empty → set TOFU. If engagement_status empty → set NEW. If intent_score empty → set 0.
2
Check: if owner is empty → assign to default rep queue
3
Check: if no open opportunity → create opportunity in Lead In stage
4
If phone OR email already exists on another contact → flag for merge review
CriticalGHL does not auto-merge. Create task "Duplicate review: {{first_name}}" assigned to admin. Monthly dedup sweep in addition.
WF-2
Stagnation monitor — runs daily at 8am
▶
T
Trigger: Daily scheduled workflow (8:00am business timezone)
F
Branch 1: TOFU contacts with last_activity_timestamp > 24hr ago
→ Set engagement_status = STALLED. Create rep task. Enrol in SMS re-engagement.
F
Branch 2: MOFU contacts with last_activity_timestamp > 3 days ago
→ Create task "MOFU STALLED." Move to Stalled pipeline stage. Send nurture email.
F
Branch 3: BOFU contacts with last_activity_timestamp > 48hr ago
→ Create manager task "BOFU at risk." Flag in Slack #sales.
F
Branch 4: Any contact no activity 7+ days → lifecycle_stage = RECYCLE
→ Enrol in 12-Month Passive Nurture. Remove from active sales sequences.
WF-3
Intent score updater — on every behavioral event
▶
T
Trigger: GHL email event (open/click) OR SMS reply OR call activity
2
Code step: calculate score delta
const w = {sms_reply:3, email_click:2, email_open:1, page_visit:1, call_connected:3, booking:5, estimate_viewed:4};
const delta = w[inputData.event_type] || 0;
const newScore = parseInt(inputData.current_intent_score || 0) + delta;
const stage = newScore >= 5 ? 'BOFU' : newScore >= 3 ? 'MOFU' : 'TOFU';
output = [{newScore, stage, delta}];
3
Update contact: intent_score, lifecycle_stage (if promoted), last_activity_timestamp, engagement_status = ENGAGED
